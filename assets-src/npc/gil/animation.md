# Gil 摇椅待机

权威模型为同目录 `gil.bbmodel`，复用 `建模试作/Gil原创制作/v1/Gil-v1.bbmodel` 的全部静态骨骼、几何与材质。闭眼、胡须、服装、坐姿和椅子保持原样；不制作站立或行走。

Gil 是在公会坐着打盹的老年男性。依据原版 AdventureGuild 地图的摇椅动画，采用缓慢后仰再回落的动作。原版四块图块同步循环，11 帧，每帧 250 毫秒，共 2.75 秒。二维原版只有三个离散姿势，不能照搬停顿到三维：初稿短促摆动后长时间静止，用户明确反馈不连贯、不自然。

修订版 `animation.gil.idle` 为 2.75 秒无缝循环；仅控制 root 的 X 旋转和 Y/Z 平移。后仰范围 0.5°–5.5°，连续余弦缓入缓出，在两端换向而不冻结；角度是三维适配值，并非原版数值。每秒 40 个线性采样关键帧供原生播放器与 Blockbench 同步求值。人和椅子刚性一同摇动，手、座面和靠背接触不变，根平移按摇椅支撑点补偿，不给眼睛额外轨道。

常驻待机；对话不切到站姿或回头动作。不参与行走混合；闭眼角色不添加眨眼。

验证：两个完整周期、661 个生产 NativeNpcPose 样本，摇椅最低点相对地面误差小于 0.000001 模型单位；55 帧独立 Blockbench/Java 骨骼矩阵最大差 0.000004。实际编辑器完整循环预览为 `preview/gil-rocking.gif`。未启动额外游戏客户端，尚未进行游戏内外观验收。
