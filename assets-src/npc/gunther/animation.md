# Gunther 基础动画与接入（2026-10-04）

正式动画源为 `gunther.bbmodel`，参数为 `motion.json`，由 `assets-src/npc/models.json` 注册。输入是用户新版 `建模试作/Gunther原创制作/v1/Gunther-v1.bbmodel`；原制作工程保留。原版角色贴图用于识别角色特征，现有日程仍是 600 起站在博物馆 `gunther_counter`，未增加日程、道具或专属表演。

## 角色与动作

成年博物馆管理员采用沉稳、克制的姿态：肩放松，双手稍有左右差，胸口呼吸清楚可见。双腿与鞋底保持稳定，头、肩和手稍晚于胸口响应。原有脸、帽子、胡须、蓝外套、白手套和酒红鞋保留；未新增嘴巴、瞳孔或眼球位移。

| 项目 | 正式实现 |
| --- | --- |
| 待机 | `animation.gunther.idle`，8.8 秒循环，两个约 4.4 秒的呼吸；胸衣缩放与躯干、肩、手、头的延迟随动分开。 |
| 眨眼 | `animation.gunther.blink`，0.23 秒；约 65 ms 闭合、短保持、较慢睁开。连续肤色眼睑退入头内，默认编辑姿势也是睁眼。 |
| 眨眼排程 | 使用现有独立 UUID 时钟，间隔 4.2–8.1 秒、时长倍率 0.96–1.16、双眨概率 6%；回看眨眼沿用公共优先权。 |
| 行走 | `animation.gunther.walk`，1 秒归一化左右各一步，完整周期路程 0.784333 格；平地低抬脚、约 9.6–35.2° 屈膝，身体上下全幅 0.50、左右移重全幅 0.76 模型单位。 |
| 步频 | 例行 NPC 使用当前公共播放器的固定作者步频，约 0.918 周期/秒；剧情替身使用现有路程时钟。未改公共步频策略。 |
| 回看与聊天 | 使用当前同步注意力事件与公共转身／返回过程，角色独立脚底参数；待机触发、聊天保持和结束返回、移动接管与触发冷却沿用现有系统。 |

呼吸与行走的通道所有权、0.18 秒渐入／0.22 秒渐出，以及退出接地修正由现有播放器处理。白眼、眼镜与眉毛的位置保持固定，只有完整眼睑遮挡眼区。

## 分组与支撑

- 髋高 12、膝高 6、鞋轴高 1.5、真实鞋底 0，肘高 18。骨骼左右采用运行时的解剖侧约定，没有镜像贴图。
- 肘、膝、踝和腰使用连续权重表面，不显示关节填充块；新增 `hipSkinHeight=3`，让裤腰缝在骨盆上、下方渐进跟随大腿，解决公共转步平移大腿时的裤腰脱接。
- 衣摆改为骨盆附属，避免跟着肩部扭转。两侧外缘各补 0.45 单位以避开原裤褶层，去掉埋在裤腿中的内侧面；配色与贴图 RGBA 完全不变。
- 短衣摆采用 0.25 单位表面行距与按短衣长适配的连接过渡；碰撞计算使用真实髋部蒙皮后的腿面。原有长裙／长披风仍用原行距与过渡参数。
- 后颈发片是原有刚性结构，颈部软限幅 yaw 12°、pitch 6°，由胸肩承担剩余视线转角。实际 130° 回看／聊天预览中，后颈发块与上臂的有向包围盒无相交。

## 源码接入

新增 Gunther 正式源注册、独立速度／眼高参数与行走能力；博物馆日程及点位保持不变。普通实体和剧情替身按当前所有权清单进入原生渲染器，不使用 GeckoLib。旧 Gunther 几何、动画与贴图退休，小地图继续用原图标并改为匹配新贴图路径。

Blockbench 的生产表面预览使用编译后实际图集、骨骼矩阵和蒙皮／衣摆表面，另与编辑器独立骨骼求值比较。不透明身体和透明镜片分别持有互不重复的顶点缓冲：725 个身体面、3 个镜片面，合计 728 个面，每面只提交一次。

此前交付的预览有双人重叠，判定无效：一次失败的预览留下了完整 Gunther 场景网格，后续捕获叠加了新模型；镜片绘制还错误地共用了身体顶点缓冲。现已移除经贴图与场景 UUID 核实的残留，只重绘正式模型；捕获前检查旧表面与源方块是否同时可见，结束后清理临时网格和材质。四种动画、角度图和最终截图均重新捕获，未改外观或动作曲线。
