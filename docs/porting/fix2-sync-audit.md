- 保留 PoseStack 的位置/法线矩阵及 `finishNanoTime`，使用 1.20.1 的 `renderChunkLayer` 和 BufferBuilder API。
- Oculus 1.8.0 子视图交换实际 `PipelineManager.pipeline`，分别保留材质设置、即时顶点状态和外层相机状态；移除该版本不存在的新 Iris 字段依赖。

- 新网络测试使用 Forge 自定义载荷封装；Java 21 集合调用转换为已有 Java 17 兼容辅助方法。
- 新版整棵棕榈树已退役。旧测试改为验证隐藏目录、拒绝新放置、旧主块/扩展格迁移及不覆盖邻居或玩家替换块；其余地面变体测试完整保留。现有模型/建筑覆盖数量按源资源的真实注册同步。
- 手工模型导出器及账本使用 Forge `loot_tables` 路径；姜岛状态物品继续使用 `BlockStateTag`，不回退为 1.21 components。
