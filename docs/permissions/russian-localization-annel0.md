# Russian localization: Annelo (annel0)

- Author: **Annelo ([annel0](https://github.com/annel0))**.
- Source repository: [annel0/Starfield-Pastoral](https://github.com/annel0/Starfield-Pastoral).
- Record added: **2026-09-14**. This is the documentation date, not the original message's timestamp.
- Source of this record: the project maintainer supplied the author's message. An original message permalink and timestamp were not supplied with it.

Annelo clarified that the Russian localization in that fork was entirely their own work. Earlier references to a translation team or other translation contributors were inaccurate. This credit concerns the translation work originating in the fork, rather than attributing all subsequent official-project localization changes to Annelo.

## Permission statement

The following is an unchanged excerpt from the message supplied by the project maintainer:

> The Russian localization in my fork was created entirely by me. There were no other translators or contributors involved in the translation itself.
>
> Since Starfield Pastoral has evolved significantly since then and now has proper localization support in the main project, maintaining a separate translation fork no longer really makes sense.
>
> So I would like to explicitly give you permission to use my Russian translation freely in the official project.
>
> You may use, modify, rewrite, merge, redistribute, and continue developing any part of the Russian localization created by me in `annel0/Starfield-Pastoral`, including in future versions of Starfield Pastoral.
>
> This permission is permanent and royalty-free, and you do not need to ask me for additional permission in the future.
>
> Credit is appreciated, but completely optional.
>
> Of course, this permission only applies to the Russian localization work created by me and does not grant any rights over the original Starfield Pastoral code or third-party assets.
