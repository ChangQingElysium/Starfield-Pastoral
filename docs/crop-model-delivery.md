# 作物模型制作与交付

适用于本次制作、修订或明确要求审查的作物及其受影响状态。共享生成器、公共材质或统一规格改变时，扩大到所有受影响资产；不自动复查全库。局部材质修改保留已核实且未受影响的空间结构，发现结构问题时才回到白模。已有证据仅在资产内容、规则和验证条件仍适用时复用。

- 作物每批制作完成后删除过程性文件：临时作者脚本、构建数据、参考裁图、中间方案、调试空间数据和重复重载截图。保留最终总工程、独立状态、PNG、状态映射、最终预览与交付审查记录；原始源文件及要求保留的旧版成品不属于待删过程文件。
- 二维作物原图只是单一投影，不是整株三维结构或叶果总数的限制。按物种和阶段补全环绕生长的分枝、叶簇、花果与攀附连接；不可集中在展示正面，或用双面贴图、负极壳代替背侧生长。白模起独立检查正背左右、俯视及斜向遮挡，允许合理疏密、不对称，禁止机械复制四份正面。多视角截图只有在实际检查空间结构后才算验收证据。
- 作物空间审查逐阶段记录实际判断：枝叶从哪里连接、向哪些方位展开、花果是否符合当前阶段、转到背侧是否仍有合理植株体量。已长成的植株若换个方向只剩空杆、薄片边缘或轮廓壳，退回白模修订；不能靠换展示角度、加双面材质或增厚描边通过。播种与幼苗按其阶段判断，不为凑满四面提前添加叶果。
- 作物参考分析须区分原图可见事实与三维补全设计；忠于原版不等于挤出一张正面贴图。每批空间自审记录最薄弱视角及判断依据，分别检查背面材质完整性与背侧生长结构，不能以其中一项替代另一项。
- 负极轮廓必须从前后、左右、上下保持连续，不能只检查一个展示视角。带符号反向几何的面名不等于普通体块的物理面位置；核对实际朝向、端面封口及相邻壳之间的连接，消除缺口、悬空细线和内部重叠面。
- 负极壳必须在正常观看尺寸及一格土面参照中发挥可见作用；“存在负尺寸元素”不算验收。固定相机、尺度、光照做开关及厚度对照，按部位选择外扩量和同材质轮廓色，禁止惯用极细壳后只靠放大截图证明有效。0.2–0.4 可作为试验范围，不能作为全作物统一参数；过粗遮住主体、连接处漏线同样退回修订。厚度改变后同步修正带符号几何、物理封口与衔接及 1 像素／单位 UV，不能增加纹素密度、整体降饱和或用描边补偿空间结构。本次范围内缺少有效证据或轮廓发生变化的作物逐种复查并记录；未经本项检查的历史自评不能代替验证。
- 作物必须消除会产生深度竞争的共面或近共面重叠，包括主体、负极壳、相邻部件以及实际承载的泥土／耕地／盆栽表面。按最终分组旋转后的世界面逐阶段检查，不能只比较未旋转包围盒。模型接地基准定义为局部 Y=0，接入时对齐实际承载表面；土面验收也必须使用该基准，禁止偷偷降低参照土面掩盖问题。关闭与地面共面的隐藏底面，接触壳按物理面拆除重复内部面并连续衔接；不以换视角、polygon offset 或未约定的微小偏移掩盖重叠。透明薄叶正反面必须反向绕序、背面剔除，不能叠放两个同向可见面。修改后同步受影响的独立状态及其截图、面数和重载核验；尚未接入游戏时不宣称已验证游戏内无频闪。
