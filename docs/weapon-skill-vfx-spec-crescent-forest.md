# 月牙斩与森林祝福动作 / VFX 实施规格

> 目标版本：Minecraft 1.21.1 / NeoForge
> 适用技能：`crescent_slash`、`forest_blessing`
> 本文只规定表现，不改变技能伤害、索敌、治疗量和冷却。

## 1. 共同约束

- 两个技能的动作长度都是 8 tick，服务器生效帧都是第 3 tick。
- 客户端以动作开始包抵达的本地 tick 作为播放零点；不得直接用服务器绝对 tick 跳过前摇。
- 第 3 tick 必须同时是武器速度最高、刀刃经过目标方向、服务器结算命中的时刻。
- 第一人称和第三人称共享同一阶段：准备（0–2）、打击（2–3）、随动（3–5）、回收（5–8）。
- 拖尾只记录真实刀身运动，不生成脱离武器的伪剑气。
- 未命中时只有挥空声和短拖尾；命中火花、命中声和镜头反馈只由服务器命中包触发。
- 特效默认接受世界光照与遮挡。不得使用穿墙、全亮白片或大面积屏幕覆盖。
- 低粒子设置下仍由动作和刀身轮廓表达技能，粒子只是材质与状态说明。

## 2. 月牙斩

### 2.1 动作意图

月牙斩是弯刀的宽幅横斩，不是魔法弹。力量来源是短促反向拧身后，以躯干带动肩、手和刀刃完成一次干净的横向切割。

| Tick | 阶段 | 第一人称 | 第三人称 | 表现事件 |
| --- | --- | --- | --- | --- |
| 0 | 起始 | 正常持刀 | 正常站姿 | 无 |
| 1 | 收刀 | 刀柄向惯用手侧收，刀尖略后置 | 躯干反向扭转，副手张开平衡 | 无 |
| 2 | 压缩 | 刀刃停在画面惯用手侧，保留准星视野 | 重心压低，肩线完成蓄力 | 拖尾尚未出现 |
| 3 | 命中 | 刀刃高速横穿准星下方 | 躯干转正并越过，主手横切 | 服务器结算、挥砍声、拖尾峰值 |
| 4 | 随动 | 刀刃到达另一侧，速度快速下降 | 主手过身，副手反向制动 | 拖尾衰减 |
| 5 | 定势 | 保留一帧清楚终点，不抖动 | 躯干停止旋转 | 拖尾结束 |
| 6–7 | 回收 | 回到正常持刀 | 重心与双臂回正 | 无 |

### 2.2 视觉分层

1. **刀刃主体**：真实物品模型。
2. **运动轮廓**：窄幅刀刃拖尾，外缘最亮，靠近刀柄处迅速透明；寿命不超过 3 tick。
3. **命中切线**：目标表面出现一条短而有方向的金属切线，4 帧内消失。
4. **碎屑**：最多 3 个细小金色火花，沿切线法向散开。
5. **声音**：挥空使用一次原版 sweep；确认命中追加低音量 strong/crit，不使用紫水晶魔法音。
6. **镜头**：仅本地施法者确认命中时给予极轻、2 tick 的回弹。

### 2.3 色彩与资源

- 主色：旧金 `#D6A84A`
- 刃口高光：暖白 `#FFF1C2`
- 暗部：棕金 `#76502A`
- 禁止使用八向星芒、圆形爆炸和大面积纯白。

## 3. 森林祝福

### 3.1 动作意图

森林祝福首先是一记真实的斜向挑斩。刀刃命中或挥过后，森林魔力沿武器运动被“唤醒”，再附着到施法者身上形成持续恢复。它不能演成站桩举手施法。

| Tick | 阶段 | 第一人称 | 第三人称 | 表现事件 |
| --- | --- | --- | --- | --- |
| 0 | 起始 | 正常持剑 | 正常站姿 | 无 |
| 1 | 引势 | 刀刃向惯用手侧下方沉降 | 主肩下沉，身体略向目标侧 | 无 |
| 2 | 聚力 | 刀尖保持低位，副手收近身体 | 重心落在后腿 | 拖尾尚未出现 |
| 3 | 命中 | 刀刃斜向上切过画面中央 | 后腿蹬地、躯干与主手上挑 | 服务器结算、短绿色刃纹 |
| 4 | 释放 | 刀尖达到上方终点 | 主手停在肩线上方 | 叶片从刀路末端脱离 |
| 5 | 定势 | 短暂停留，明确“斩后生效” | 身体恢复稳定 | 祝福附着 |
| 6–7 | 回收 | 回到正常持剑 | 双臂与重心回正 | 持续恢复继续 |

### 3.2 视觉分层

1. **刀刃主体**：真实森林剑模型。
2. **运动轮廓**：细窄、分段的深绿刃纹；金绿色刃口只占很小面积，寿命不超过 2.5 tick。
3. **命中材质**：目标处生成 2–4 片受切线带动的叶片，不生成爆炸。
4. **祝福附着**：激活时从刀路终点向施法者胸口回收一枚种光；随后每个治疗节拍只产生一枚短命种光和两片上升叶片。
5. **持续状态**：种光与叶片围绕玩家下半身到胸口上升，不画地面圆环、不形成粒子柱。
6. **声音**：挥砍声负责攻击；激活使用克制的叶片摩擦与低音量经验音，不连续循环。

### 3.3 色彩与资源

- 主色：森林绿 `#3F7D49`
- 新芽高光：嫩黄绿 `#B8C96D`
- 暗部：深叶绿 `#244D32`
- 少量暖金：`#D5B85A`
- 禁止使用完整圆环、绿色烟雾墙、随机满屏 `HAPPY_VILLAGER`。

## 4. 性能预算

- 拖尾按每 0.2 tick 一个样本进行时间量化，不按渲染帧直接追加。
- 每名施法者最多保留 18 个拖尾样本：3 tick 月牙拖尾理论需要 16 个，仍保留 2 个容量余量。
- 单次补采最多 4 个中间样本，避免卡顿恢复时产生无界顶点。
- 月牙斩每个目标最多 1 条命中切线和 3 个火花。
- 森林祝福激活不超过 6 片叶子；每次治疗不超过 2 片叶子和 1 枚种光。
- 森林祝福完整 4 秒周期：无目标共 30 个粒子；命中目标时共 32–34 个，平均不超过 8.5 个/秒。
- 所有表现必须在世界切换时清理；距离摄像机超过 48 格时停止渲染拖尾。

## 5. 静态验收

- 服务器生效帧与客户端动作接触帧都为 tick 3。
- 两个动作都从正常持刀连续进入，不允许第 0 帧瞬移。
- 拖尾纹理的刀尖边缘亮于内部，刀柄侧 alpha 接近 0。
- 月牙命中贴图没有放射状星芒。
- 森林祝福没有地面圆环资源或圆环粒子类。
- 森林祝福 80 tick 内必须恰好产生 8 次治疗节拍表现。
- 编译、payload codec 测试和技能 runtime 测试通过。
