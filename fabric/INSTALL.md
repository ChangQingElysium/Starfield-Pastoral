# StardewCraft Fabric 1.21.1 候选测试包

版本：0.6.3fix2。日期：2026-10-15。

## 安装

1. 准备现有的 Minecraft 1.21.1 测试实例，使用 Java 21 和 Fabric Loader 0.19.5。
2. 将本包 `mods/` 中三个 JAR 放入实例的 `mods/` 目录：StardewCraft、Fabric API 0.116.17+1.21.1、Forge Config API Port 21.1.6。
3. 从现有启动器进入该实例，先在测试存档验收资源、画面和操作。

Porting Lib 五个所需模块及 Maven 版本库已经内嵌。三个 JAR 的文件大小与 SHA-256 记录在 `SHA256-manifest.json`，用于核对下载与复制后的内容。

## 已取得的验证证据

- 全部 4411 个上游 Java 源文件参与编译，资源合并、12 语言检查通过。
- 755 项平台测试与 39 项 Python 来源/转换检查通过。
- CLIENT 环境真实 Mixin 字节码转换：199 个目标成功，23 个未安装的可选目标跳过，0 失败；此过程没有打开游戏窗口。
- 20 个定向 GameTest 的最后一次结果均通过；未执行全部 908 项。太阳能测试曾因区块未加载而放到地下失败，预加载后原测试通过，历史记录保留。
- 正式重映射 JAR 在独立正常地形专服启动，并完成保存、正常停服及同存档重开读取持久标记。无窗口协议 peer 已完成登录、退出及同 UUID 重连。

补充修复：客户端世界/区块加载卸载事件、按事件类型分配自动订阅总线，以及 36 个 Jade 和 1 个 JEI 插件的可选发现入口。403 个物理客户端订阅类的真实 Loader 类定义与方法签名解析通过，没有执行游戏初始化。

## 本轮仍需验收

客户端完整资源烘焙、模型画面、HUD/GUI 在不同缩放下的交互，以及真实玩家联机操作。无窗口协议检查只证明已检查的握手和连接流程，不代表全部业务消息与菜单已经实测。

Jade、JEI、AppleSkin 属于可选集成，请使用对应 Fabric 版本。GeckoLib 钩子按官方 4.8.2 JAR 核对了映射，尚未在该组合中实测；Sodium、Iris、Continuity 和旧存档完整迁移也尚未取得运行验收。
