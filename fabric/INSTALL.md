# StardewCraft Fabric 1.21.1 候选测试包

版本：0.6.3fix2。日期：2026-10-23。

## 安装

1. 准备现有的 Minecraft 1.21.1 测试实例，使用 Java 21 和 Fabric Loader 0.19.5。
2. 将本包 `mods/` 中三个 JAR 放入实例的 `mods/` 目录：StardewCraft、Fabric API 0.116.17+1.21.1、Forge Config API Port 21.1.6。
3. 从现有启动器进入该实例，先在测试存档验收资源、画面和操作。

Porting Lib 五个所需模块及 Maven 版本库已经内嵌。三个 JAR 的文件大小与 SHA-256 记录在 `SHA256-manifest.json`，用于核对下载与复制后的内容。
